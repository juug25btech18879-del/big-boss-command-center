# BIG BOSS COMMAND CENTER

A React + Vite single-page web application for the Tech House challenge.

## Requirements
- Node.js 18+ recommended
- npm

## Run
```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite.

## Build for submission
```bash
npm run build
```

The production build is generated in `dist/`.

## 12 Mandatory Features
1. Contestant Management — 8 contestants
2. Live Leaderboard
3. Task Management
4. Point System
5. Captaincy
6. Nominations
7. Immunity
8. Danger Zone
9. Big Boss Announcement
10. Task Timer
11. House Statistics
12. Eviction

All features are connected through React state and work without a backend.
